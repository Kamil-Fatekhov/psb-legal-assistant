# Юридический ассистент ПСБ

Проект для трёх участников. Корневой `solution.py` содержит код стартера организаторов и служит отправной точкой для доработки сабмита. Общие типы находятся в `contracts.py`, методы новых модулей пока обозначены через `NotImplementedError`.

| Кто | Файлы | Первый результат |
| --- | --- | --- |
| A | `knowledge/` | Поиск возвращает полные пункты 3.1 и 3.2 договора «Северный Склад». Просмотр по ID возвращает тот же текст. |
| B | `assistant/`, `solution.py` | Общее ядро принимает вопрос и историю, возвращает выводы с ID источников. Сабмит сохраняет исходный ID вопроса в CSV. |
| C | `web/` | Чат показывает ответ и открывает источники по ID. До подключения ядра можно подставить тестовый `Answer`. |

## Стыковка

- `AskRequest.history` идёт от старых реплик к новым и не включает текущий вопрос.
- `SearchQuery.as_of` задаёт дату для выбора редакции. Для условия, зависящего от конкретного события, передавайте также `event_kind` и `event_date`. `AmendmentRule.applies_after` задаёт строгую нижнюю границу даты события.
- Поиск и просмотр работают с одним `Corpus`. ID фрагмента устойчив при повторной сборке того же корпуса. `effective_from` включается в интервал, `effective_to` исключается.
- Каждый `Finding.source_ids` содержит ID подтверждающих фрагментов из выдачи. Отсутствие данных отражается в `Answer`, сбой зависимости передаётся через `DependencyUnavailable`.
- Чат и сабмит используют один `AssistantService`. Чат работает со структурированным ответом, сабмит преобразует его в строку для `submission.csv`.

Исходный пример и инструкция по его запуску находятся в [`sample_submission/`](sample_submission/README.md). Дорабатывайте корневой `solution.py`. Для первого локального прогона установите зависимости командой `python -m pip install -r sample_submission/requirements.txt` и подготовьте входные файлы и переменные API по инструкции стартера.

Проверить импорт каркаса из корня проекта можно командой:

```sh
python -B -c "import contracts, knowledge.indexer, knowledge.search, knowledge.sources, assistant.service, web.chat, solution"
```

## Локальная проверка поиска

`CorpusIndexer.build()` принимает путь к папке с TXT и возвращает каталог `Corpus`.
Эксперимент с эмбеддингами рассчитан на папку `knowledge-base/` в корне проекта.
Для него нужны `langchain-community`, `langchain-text-splitters`, `langchain-huggingface`, `sentence-transformers`, `torch` и `numpy`.
Запускайте из корня после установки этих зависимостей.

```sh
python -m knowledge.test
```
